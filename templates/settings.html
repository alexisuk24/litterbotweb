Whisker app

Sync schedule
How often activity, clips and robot status are fetched from Whisker; notifications are checked after each sync. Applies straight away. Use Refresh to sync sooner.
Send cat corrections to Whisker
When you change which cat a visit was, mark it Unknown, or revert it on the Events page, the change is also made in your Whisker account. That also corrects the cat's weight history in the Whisker app. Whisker only accepts changes to visits from the last 7 days; older corrections, and notes, stay in this app only.
Clip list timezone
The timezone sent when asking Whisker for clips; dates are read as days in it. Whisker leaves recent clips out of the list when this doesn't match the robot, so leave it on Robot unless clips go missing. Takes effect at the next sync.

Notifications

Pushover notifications
A push notification when a cat gets a new warning on the Cats page, or a robot has a problem. Checked after each sync. Each problem is sent once; it's sent again only if it clears and comes back. Several new ones at the same sync arrive as one notification.
Pushover keys
Your User Key is on your pushover.net dashboard. For the API token, create an application there (any name, e.g. Litter Robot). Saved keys aren't shown again; leave a field blank to keep it.
